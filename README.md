# Оснвная информация о проекте
## Как я добавил сюда git?
Я ввёл команду:
```bash
git init  # Инициализировал для данной папки
git add . # добавил все файлы в папке
git commit -m "First commit. Make readme file."
git remote add github https://github.com/AlfaDecibel/RTL_verification_project_template_ru.git # добавил репозиторий github
git remote add gitflic https://gitflic.ru/project/alfadecibel/owner-avatar-rtl_verification_project_template.git # добавил репозиторий gitflic
git push -u gitflic master
```
